## Ordinary delay producer and consumer

For selected Execute object `9` with successful time-data unpacking, the compiler parses amount `ORAFROM` and multiplier `ORAFROMMULTI`. Multipliers `1/60/3600` select units `s`/`m`/`h`, then format `{0} SLEEP({1}%,"{2}")`. The multiplier chooses a unit; this source path does not multiply the amount first.

The selected native script interpreter checks the SLEEP prefix, starts the amount cursor at index `6`, converts digits until `%`, skips the following comma/quote and copies the unit until the next quote. It then requests imported `SLEEP(amount,unit)`. This concretely aligns the selected producer delimiters with the native call arguments for ordinary bounded decimal input.

The same-build candidate `libdomotica` helper distinguishes exact `ms`, then selected first-character `m`/`h`/`s`; minutes/hours multiply by `60/3600` and seconds retain the amount. Runtime dependency binding, overflow/cancellation, scheduling and elapsed timing remain unexecuted.
