This candidate migrates the next ten accepted Device definitions into the shared Machine KB on `docs/devices-foundation`. Sixty-two public originals were matched to existing registered fingerprints and archival metadata; 60 needed new KB source references, while two were already represented. The retained private catalogue supports the accepted pages but is not published or copied into the KB. Missing exact-product PDFs remain documentation gaps; explicit SKU-to-item relationships establish identities.

The four projections were regenerated together. Candidate totals are 155 documents, 1,915 sections, 1,839 retrieval chunks, 16,875 claims and 25,850 live lifecycle identities. Public schemas, compatibility version and schema-pinned generator identifier are unchanged. Allocation appends above existing mappings and complete lifecycle history. All 10,004 existing claim seeds and generated claims, curated contexts, reference seeds, 1,502 generated chunks and 16,109 lifecycle entries are unchanged. Previously registered catalogue/source relationships acquire reciprocal links from the additional graph.

The repeated-table workload exposed redundant section hashing and source-unit derivation per claim. These derived values are now reused only within one immutable render traversal. A later render recomputes them; changed source sections still invalidate pinned reviews. This does not refresh fingerprints, bypass evidence checks or alter output schemas. A regression checks both one derivation per claimed Device section and rejection after a source change.
