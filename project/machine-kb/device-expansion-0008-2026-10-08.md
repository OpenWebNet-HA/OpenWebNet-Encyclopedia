# Device Machine KB expansion, batch 8

This batch migrates the twenty accepted definitions OWN-DEV-0108–0127. This raises the published inventory to 131 integrated and 79 pending definitions. All eight acceptance checks were verified in the closed Device queue before ingestion. This migration preserves accepted evidence; it is not independent semantic certification, a new Device review, a merge, a tag or a KB release.

## Scope and conservation

The shared IR accounts for all 6,242 prepared source units: 5,950 claimed and 292 reviewed nonclaim units retained as source inventory/navigation in the corpus, retrieval chunks and reference registries. All 7,915 new assertions retain the governing unit with every table header/cell, qualification, exact section/unit fingerprints and atomicity/evidence keys. Domains and defaults are separate assertions with 1,939 source-scoped configuration entities. The original 47,290 claims and contexts, prior references, identity mappings and lifecycle entries remain unchanged.

Ninety-one already registered documentation originals are reused by manifest fingerprint and byte length, including 89 first-time KB source-reference entries. No new original was acquired or archived. Source inventory inclusion does not claim new inspection of linked payloads, firmware, software or unexamined document editions.

The migration combines the already completed Device acceptance review, a review of the governing identity/capability/procedural and reconciliation boundaries, and exact programmatic conservation of repeated configuration schemas and every conversion branch. Shared schemas remain separately scoped to each Device/Firmware/placement; identical cells do not equate installed hardware. Numeric conversion sequences are checked against their complete enumerated branches rather than truncating them to example rows. Blank commercial-description cells remain explicitly empty source cells rather than being supplied by inference.

Network examples and the concrete manufacturer-published installer password on 0108 are redacted before IR construction; the abstract password width remains. Contextual privacy preparation preserves exact public technical-sheet identifiers, including Dutch editions and citations without a language suffix, while still removing installed Device identifiers. The earlier 0119 identifier detection was a public sheet-code false positive, not an installation identifier. Only the two unpublished documents require new preparation pins; all previously published source preparation and curated pins remain unchanged. Catalogue defaults and association labels are not inspected payloads or observations.
