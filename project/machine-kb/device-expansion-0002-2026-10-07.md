# Accepted Device Machine KB expansion, batch 2

This candidate integrates fifteen additional accepted Device definitions into the shared Machine KB IR and all four projections. It migrates existing evidence and acceptance outcomes; it does not repeat Device reviews or claim an independent release certification.

## Selection and conservation

The current closed inventory selected OWN-DEV-0014 through OWN-DEV-0029, excluding OWN-DEV-0021 because it was already integrated. The candidate contains 35 integrated definitions and 175 pending definitions. Every selected page passes the existing eight-check acceptance gate.

All 2,560 prepared source units have a pinned, reviewed claimed or nonclaim disposition. The candidate adds 3,171 claims, including nine independently usable source assertions for material disagreements or differing UI contexts. Table cells, headings, governing prose, firmware/build tuples, commercial/system relationships, Module/Object/Virgin associations, fields/domains/defaults, conditions, filters, conversions, modes, connections and parameter/package records are conserved. No linked parameter payload, software binary or installed state is inferred from an association.

Thirty-nine previously registered public originals are reused by their SHA-256 and manifest byte-length records, including manufacturer HTML for EAN evidence. Thirty-five acquire new stable KB source references; four reuse existing references. No new PDF or original artifact was added. Unretained documents remain discovery leads and do not acquire manufacturer-source records.
