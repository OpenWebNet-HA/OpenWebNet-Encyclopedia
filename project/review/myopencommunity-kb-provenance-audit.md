# MyOpenCommunity Machine KB Provenance Audit

This audit starts from `a1566fbeee92a1a642b9569a106663e282a6b999` on `docs/myopencommunity-integration`. Its boundary is the accumulated semantic findings in the Integration, Reassessment, Coverage, Remaining Source, Intermediate, Transport, Energy, HVAC, Alarm, Lighting/Automation, Scenario, Auxiliary, CEN, Sound, Alarm-clock and Equalizer review records. Component inventories, field screens, indexed-only edges and search matches are not findings. The configurator review is used only for its archived simulator comparison; manufacturer vocabulary remains its separate evidence lineage.

## Baseline trace

The baseline has 7,448 claims. Its public source registry contains no original MyOpenCommunity artifact records. Reviewed historical sections frequently have no atoms, while mixed sections already contain properly attributed specification, database or capture claims. Page text, limitations and review links survive into the reading/search corpus, but page-level provenance alone cannot identify the archived implementation or examination method. Coverage annotations explicitly defer atomic extraction; the 98 existing claims in 62 MyOpenCommunity-mentioned coverage rows are not 98 recovered findings.

The audit follows reviewed explanations to their underlying pinned source/test bodies, retained execution records and existing/new claim IDs. It does not rerun complete archived suites, perform a new hardware test or certify repository exhaustion. The original source pins, file bytes, Git blobs, SHA-256 and line bounds are independently checked from retained Git objects. No preserved repository, synced source, code payload or private fixture is changed or copied into public artifacts.
