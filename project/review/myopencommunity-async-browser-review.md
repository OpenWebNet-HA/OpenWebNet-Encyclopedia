## Findings and canonical placement

[Sound Diffusion](../../functional/who-22-sound-diffusion/#historical-local-playback) extends the existing local playback table and qualifications. [UPnP Multimedia](../../functional/who-26-upnp-multimedia/#browser-state-and-recovery) gains a compact browser recovery reference, separate from the numeric WHO namespace and canonical XML transport. Neighboring Sound System, Sound Diffusion, UPnP and stream-parsing material is read before editing. No new canonical page or procedural guide is needed.

Discovery replacement checks mounted/nonempty path before signalling cancellation to its predecessor. A failed mount/path precondition therefore does not cancel an existing request. Directory changes are unchecked: controlled missing-root traversal falls back to the process current directory. The source class supplies no cancellation/join destructor. Parent-owned completion watchers do not establish that the original worker stops. Previous flag lifetime and current-source callback findings retain their IDs and limitations.

Metadata extraction starts a separate null-output process, accumulates stdout until required keys or the strict greater-than-five-second guard, requests terminate and waits 300 ms without checking the wait result. Failed startup or early process exit does not end the loop directly. Partial/empty metadata is not a success code. The pinned parser selects the last match; earlier helpers used the first match and waited without a time guard. Watcher replacement only requests deferred deletion. Completion reads the current member watcher and emits before cleaning that member. Controlled native Qt event delivery reproduces old-watcher completion reading the replacement result, and synchronous notification starting a replacement that the original cleanup then deletes. BtExperience merges supplied metadata without track/request association.

Browser entry/context changes occur before acknowledgement. Selection/context errors do not roll them back. The root-return branch retains context, reset retains pending context and shared queued commands, and late directory responses can alter level after reset. Error signals have selective loading-reset hookups: directory-change error in the base model, list-retrieval error in the paged model, neither empty-directory nor generic-error in those constructors. This does not establish the behavior of every external UI consumer.

Pages use one-based rank and four-entry requests. Filtering follows decoding and preserves unfiltered total, while the paged model advances only for accepted entries. A controlled empty filtered page with positive remaining count causes three requests of rank 1. Inactive/older-ordinal replies are discarded locally, without cancelling queued commands. Local ordinals come from last sent bookkeeping, not validated wire response identity. Offline/busy-SID queueing, welcome gating and ACK 200 release are implementation policies; reset is unimplemented and session cleanup preserves the queue.
