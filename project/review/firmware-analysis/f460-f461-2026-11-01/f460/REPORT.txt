# F460 2.0.12: bounded static first pass

The verified F460 archive contains a fresh AArch64 platform, normal/recovery ext4 filesystems, a raw ARM64 kernel, six device trees, a Cortex-M payload, a packaged scheduler/matrix stack and a75-table embedded catalogue. This first pass establishes packaged identities and declarations. It does not establish running services, installed configuration, accepted commands, physical capabilities or a shared implementation with MyHOMEServer1/F461 merely from filenames.

Every regular file was checked by header, independently of extension, for the explicit leading signatures in HEADER_CENSUS. This found1 normal/1 recovery SQLite files. Other listed database-extension candidates and unknown/embedded/container formats remain a bounded gap; no universal database-absence claim follows.

DATABASE_STRUCTURE provides every table's count, column declarations and schema hash, with no row/default/credential/configuration values exported. Queries used immutable read-only URI, query_only=ON and trusted_schema=OFF; no vendor SQL expression was evaluated. The catalogue differs in exact file bytes from MyHOMEServer1's earlier packaged catalogue. This first pass does not equate reused numeric IDs, assess all semantic row changes or infer support for the server itself.

MHS_IDENTITY_COMPARISON compares only exact hashes for selected same-path packaged binaries/libraries/catalogue. Shared names or dependency families confer no implementation equivalence; absent comparison paths are unknown. Literal MHCatalogue.db occurrences are translated through each fresh ELF's PT_LOADs into file offsets/VAs, but their presence plus sqlite imports alone does not prove a complete reader/query path.
