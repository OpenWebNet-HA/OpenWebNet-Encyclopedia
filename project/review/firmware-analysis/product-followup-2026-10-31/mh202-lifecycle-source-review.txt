## Source conclusions and necessary premises

The recovered Suite resource declares P50 `panicKey/enabling`, default string `0`, choices `0`/`1`; P51 `panicKey/command`, default action text `*15*00*01##`; and hidden P52 `panic` with empty default. The enclosing parameter data source is `configuratore/setup/sicurezza`. The actual conversion rule at `xml/prj2conf.xml:374..381` tests the full enable leaf for string `1` and declares action `copy` from `panicKey/command/action/open` to the full `panic` leaf, with from attributes delete `0` and mode `value`. That establishes a producer declaration. The vendor conversion engine is neither executed nor fully reconstructed. In particular, skipping this rule with enable `0` does not establish clearing or preservation by the whole converter; the stale-target host case is appropriately conditional.

Original MH202 taskmanager SHA256 `ce9dc7b8f78bcda6b89ba518a02c42e8ef420e23bb54f1e1606e75ae3e97966e` supports the scoped consumer join. At `0xb08c` it initially writes NUL to the destination before the imported getter call at `0xb0bc`. Exact original key strings produce the same `configuratore/setup/sicurezza/panic` path. At `0xa378..0xa380` it supplies the event full-frame string and configured buffer to imported strcmp; `0xa384..0xa388` selects equality. `0xa38c..0xa394` writes literal `1` to the command gate, and `0xa398..0xa3c4` traverses records and conditionally calls stop at `0xd47c`. The ordinary gate read at `0xa494..0xa4a0` uses the same address. These are static source and ordinary imported-contract conclusions, not an executed parser, getter, stop, callback, or physical command.

The supplied frame spelling comparison retains leading-zero significance only under the explicitly unmodified-string premise. Host inequality of `*15*00*01##` and `*15*0*1##` is not proof of a false trigger, canonicalization behavior, public address validity or bus admission. Runtime getter/configuration binding and successful export/loading remain open.

Suite release `3.5.38`, installed-package directory `1902_1.0_LGG`, catalogue default build `1.0.0` and firmware `1.0.24` remain different version scopes. The source join is conditional on compatibility and matching installed paths/values; it is not a demonstrated Suite-to-device round trip. Defaults/restoration archives do not establish an installed generated `.spt` or `info.xml` pair.

The NOBITS finding supports an ordinary fresh-process zero-fill premise. It is not an observed power-cycle reset, an implemented complete gate-clear contract, or proof of readiness. The separate mode4 setter, query cursor/readiness storage, saved-active RESTART pass and subsequent always-start pass remain separate policies.
