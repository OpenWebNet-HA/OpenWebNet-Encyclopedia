## Reading historical records

A report's date, selected scope, method and version determine what it establishes. Earlier wording such as “current”, “pending” or “final” describes that recorded assembly, not automatic approval of every later reference page. Source inspection, modeled host arithmetic, isolated original-helper execution and Physical Device observations remain different evidence classes.

Exact first copies, failed preparations, corrections and execution accounting remain supporting provenance. Several reports about the same source or reused experiment are not independent physical corroboration. Current interpretation belongs in the linked reference pages; significant corrections retain their original supporting history.

## Export representations and current references

The [editorial reconciliation record](../encyclopedia-editorial-reconciliation-2026-11-02/) distinguishes rewritten reference versions from preserved proof. Historical manifests retain their original hashes; specific old/current mappings preserve traceability instead of silently repinning old validations.

A small set of published exports has host-specific path prefixes replaced with workspace placeholders. These are representation changes, not new source bytes or replayed experiments. The [explicit representation mappings](../encyclopedia-editorial-reconciliation-2026-11-02/export-representations.json) identify every affected original/public byte identity. Local reconstruction still requires its exact original inputs and recorded dependencies; these collections are not complete runtime packages.

Manufacturer originals retain their registered archive/distribution policy. Credentials, keys, live installation values and raw private research trees do not belong in these public records.
