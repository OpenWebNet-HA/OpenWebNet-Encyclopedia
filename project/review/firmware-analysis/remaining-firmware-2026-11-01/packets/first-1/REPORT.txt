# F450 standard/PROD 2.0.10 and F455 1.1.2: bounded first exploration

The F450 packages retain identical normal root images and all 3,839 regular-file identities, but their outer packages differ. F455 is a separate opaque standalone payload. These findings concern exact retained originals, not installed devices or runtime equivalence.

## Exact applicability and package distinction

- F450 standard archive: 13,265,378 bytes, SHA256 `9e625012d3e8629bea15d608f7c1de160e971499a39f3fd86f0c68103da8b9da`.
- F450 PROD archive: 13,444,140 bytes, SHA256 `27c5640916f980be2c16fd14ed7818d8b361e69b439e7a774bd4e90e57b9b96f`.
- F455 archive: 180,196 bytes, SHA256 `cd99299fc729679b4eade46acda7bd4f5e619a0a9eac34a1f6a3b73b625a18f9`.

Both F450 fwz.xml originals are identical 790-byte files (`4b5709921d308716dbd4f9dea0ccea9f5265331ea67beb0c0076e6ee5d9d330c`). Their name/version are F450/2.0.10 and object-model labels are 1.0.52/2.0.52 (lines3-9). They declare firmware and recovery_firmware actions using the same two file labels, plus extra_download 50.xtz (lines13-24); status4 orders actions2,1,3 (lines26-29). This is manifest declaration, not actual recovery selection or installation proof.

The standard outer ZIP has three members; PROD has eight. PROD adds 50.xtz, bubl.bin, default_env.img, parts.in and u-boot.bin. Only metadata/hashes of these packaging additions are used; environment contents are not inspected or exported. Shared extracted gzip/uImage/fwz.xml and normal image hashes match. The normal image SHA256 is `92aa546baf4c330b842e6e0f0336acd264787a944c9b27838c5aacdd04ff1f10`. Each retained regular tree totals 26,156,366 bytes; all individual sizes/hashes were verified. Saved link/special-node metadata remains separate; this collector never makes or follows target links.
