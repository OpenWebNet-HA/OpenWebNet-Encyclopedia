## Private subscriber justification and callback traversal

The private monitor context at original address `0x165a4` receives a one-node native-layout connection list at offset+4. Its data is a 12-byte private connection record whose first word points to an opaque private memory address. That address is passed through as the GSocket argument but is never treated as a real GObject/GSocket or dereferenced by a vendor socket implementation.

This layout is supported by static original accept-path code: `coso!0xbc00..0xbc28` requests 12 zeroed bytes, stores the accepted socket pointer in word0, then `0xbcb4..0xbcc0` appends the connection record into context+4. The accept, remote-address, event-source and attach functions are not executed here. The fixture provides the minimal record fields consumed by the selected normal callback, not a simulation of successful socket startup.

`g_list_foreach` remains an explicit primitive. It traverses supplied data/next words and schedules the **original** callback with ABI arguments `(node_data,user_data)`. A private continuation PC resumes the saved foreach return after a callback returns. No instruction at this synthetic PC is counted as original code. Outer and inner traversal arguments are recorded independently:

- Original batch foreach invokes `0xc12c(message,monitor_context)`.
- Original `0xc134..0xc148` reads monitor_context+4 and requests foreach over the one connection, callback `0xc15c`, userdata equal to the same message.
- The private traversal dispatches actual `0xc15c(connection_record,message)`.

Thus original callback code runs; packaged GLib traversal does not. The final outer traversal remains pending at the message-free boundary described below.

## Original serializer and final send boundary

Original `0xc160..0xc17c` tests message protocol 3. It selects `0xc234..0xc23c`, passing the actual parsed object pointer and the address of a null output-buffer local to `openmsg_to_buf`. PLT `0x9ef0` is redirected to the original provider at private base `0x20000000` plus ELF VA `0x2948`. Original ELF LOAD permissions are retained. No loader/startup is run; this selected provider path needs no guessed full runtime initialization.

The original serializer checks the object's frame kind and optional fields, duplicates its WHO, WHAT and WHERE fields through explicit string primitives, selects the normal-frame formatting route and returns 0 with the newly allocated result. The actual original format is `*%s*%s*%s##`; `g_strdup_printf` is an explicit formatting/storage primitive applied to those actual native call arguments. The helper result is therefore **original serialization control/dataflow under named string primitives**, not original GLib formatting execution or a Python-supplied output frame. No original list-field callback is needed for this selected normal object because its optional argument lists are absent.

Original `0xc240` observes serializer result 0 and a buffer containing `*5*17*#5##`. Original `0xc1ac..0xc1d0` computes its actual length, passes the opaque private socket pointer, buffer, length 10, null cancellable and error-pointer local to `g_socket_send`. That final API is a record-only callback returning 10. Zero actual host/syscalls/network writes are forwarded. Error, short-send and real GSocket behavior are outside this single normal case.

Original `0xc220..0xc22c` requests release of the serializer buffer and returns through the original per-subscriber epilogue. The inner foreach continuation resumes original `0xc14c..0xc154`, which restores its frame and tail-calls `free_message`. The emulator stops at import `0x9e00`, before its first implementation instruction. Captured arguments still contain the exact original message/parsed pointers; outer pending foreach depth is 1.

The final buffer's free request is asserted. Neither the message nor parsed object nor its WHO/WHAT/WHERE string allocations appears in the captured temporary-free requests. These are observed calls with non-reclaiming free primitives, not proof of actual lifetimes, leak absence, ownership correctness or later destruction. The imported free_gchar primitive records its pointed-to temporary allocation and clears the supplied local; its original provider body does not execute. The full outer foreach/monitor list cleanup/consumer return is deliberately not claimed.
