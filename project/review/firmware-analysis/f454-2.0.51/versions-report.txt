# Run20 — packaged component versions and evidence quality

The normal-image license manifest has769 package records grouped into106 recipe/version pairs; recovery has115 records/66 pairs. These metadata counts include package splits/locales and are neither unique executable counts nor runtime-loaded components. This pass parses that metadata and independently reads selected binary version text through the authoritative ImageVFS; it does not repeat the875-ELF inventory, execute vendor binaries/version scripts, or contact a service.

A material distinction is OpenSSL: the manifest and original libcrypto text identify **1.0.1m (19 Mar2015)** even though the ABI filename is `libssl.so.1.0.0`. The vendor test script `/usr/local/bin/getssllibversion-a-os.sh` derives its result by splitting matching filenames on dots. On the packaged path `/usr/lib/libssl.so.1.0.0`, that pure filename model yields1.0.0. It is not an actual release query. This static script observation does not claim the script was run on hardware.
