# MH202 1.0.24: protocol/diagnostics first static batch

**MH202 has a concrete protocol architecture and ABI that must be scoped separately from F454.** The packaged router assigns ordinary lighting/temperature/scenario WHO values to `coso`, while diagnostics use `bt_device`. Native parser classes exported under identical names have different field layouts between MH202 libraries. The diagnostic membership mask also explicitly includes WHO1000, while the ordinary WHO→SCS conversion table has no1000 entry. That is a routing/table distinction, not a claim that WHO1000 is unsupported.

This first batch is **static only**: original ARM/JavaScript execution0, code hooks0, vendor/runtime/loader processes0, live device/bus/network I/O0. Host binutils inspect original bytes; finite Python models transcribe normal static rules. No session/credential/handshake derivation or stopped F454 branch was examined. No original firmware, old dossier, synced source, repository document or shared research state was modified.
