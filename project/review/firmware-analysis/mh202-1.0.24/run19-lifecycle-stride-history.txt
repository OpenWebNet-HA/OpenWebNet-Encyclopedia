# Run19 storage-key refinement after independent source review

The initial collector used duplicate generic `stride`/`index` keys inside one manager-command-storage dictionary. Python retained the later generic stride1, making the saved JSON adjacent to DIM6 ambiguous. The original source spans, report table and direct address arithmetic correctly distinguish DIM6 four-byte slots from DIM7 byte slots; this was a host metadata representation error.

The final collector uses explicit `DIM6_integer_stride:4`, `DIM6_integer_index:WHERE−1`, `DIM7_boolean_stride:1` and `DIM7_boolean_index:WHERE−1`. No original source, selected effect, host event outcome or execution counter changes. Event caches retain their separate four-byte stride and direct numeric-WHERE index. No original code executes.
