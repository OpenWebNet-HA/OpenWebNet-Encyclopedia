Only C memory/string operations are host-modeled: memset, strcpy, strlen, strcmp, strchr, strtok, strncpy, strcat, ordinary bounded-decimal atoi, selected sprintf formats and private strdup allocation. Full events/histograms are in the ledger/results. Each top-level call requests exactly one strdup; it allocates/copies into a bounded private guest heap. The supported sprintf cases are the selected literal WHERE`11` format with no conversions and exact source `*1*0*%s##`; another format aborts. atoi is limited to the supplied ordinary decimal strings/signed32-bit range. These finite primitive contracts are not whole libc format/overflow models. `cstring` reads are capped4096bytes. Both verified original images are read/execute only in private memory; only private stack, input and heap are writable. Explicit callbacks check every destination range and bounded source ranges. Allowed original PCs are the normalizer and fresh common native definitions/getter leaves; an unknown PC, original interrupt or invalid/protected access aborts. Code-hook and emulator instruction caps are100000 per top-level call. The final private EXIT hook stops after original top-level return. No target loader, ELF constructors outside these explicit C1 calls, host/target syscall, process or I/O runs.
