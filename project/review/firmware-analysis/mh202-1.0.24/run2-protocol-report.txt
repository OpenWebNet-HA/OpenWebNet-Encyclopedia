## 2. Selected ordinary measure/key path, with parser boundaries

The selected synthetic text is `*#1000*1*0##`, chosen to investigate the ordinary WHO1000/DIM0 route. It is **not** a hardware capture, an emitted request or a proven accepted full-parser fixture. The dataflow below is conditional on successful ordinary parsing, constructor initialization and WHERE resolution.

`libdiag::openKeyGen` `0x23f8c` creates a local `openwebnet` at `SP+4` (`0x23fac..0x23fb8`), then invokes `CreateMsgOpen(char*,int)` at `0x23fd8` using the input string's data and length. The kind load at `0x23fe0` is from `SP+0x6240`, hence object offset `0x623c`; compare4 at `0x23fe4` branches to `0x24188`. This independently connects the actual key-generator's object use to the candidate `libopen` layout rather than `libcommon`'s `0x1dec` kind offset.

In candidate `libopen`, `CreateMsgOpen` `0xb370..0xb410` copies text to object+`0x5e3c`, records its length at+`0x5e38`, strips trailing CR/LF as coded, and tail-calls `IsCorrect` at `0xb408`. The saved selected classification span `0xaf68..0xb118` identifies the read-dimension form as kind4 at `0xb09c`, calls `Assegna_chi_dove_grandezza` at `0xb0a8`, and subsequently invokes address/interface assignment when kind is not1. The field-assignment span places WHERE at+540 (`0xab30`) and DIM at+900 (`0xaba0`). **This run does not model or execute the complete preliminary grammar, address/interface assignments or final acceptance.** The conditional fields WHO1000/WHERE1/DIM0 are input assumptions, not newly executed outputs.

For kind4, the actual key-generator calls `Extract_grandezza` at `0x2419c`, `unpackKey` at `0x241b0`, and prefixes character `R` at `0x241d4`. `unpackKey` `0x229d0..0x22ba0` implements:

- Without `#`, append the literal `P0` (PIC target `0x31912`).
- With `#`, retain the prefix before the first `#`, append literal `P` (target `0x31bec`), then append one plus the number of additional `#` characters in the suffix. Thus the suffix encodes parameter count, not parameter values.

The small host reconstruction checks DIM`0`→`R0P0` and DIM`0#1`→`R0P1`. These are consistency checks of transcribed dataflow, not native C++ string/map/parser execution. WHO and WHERE are not concatenated by this selected kind4 key branch; later routing can still consult both.
