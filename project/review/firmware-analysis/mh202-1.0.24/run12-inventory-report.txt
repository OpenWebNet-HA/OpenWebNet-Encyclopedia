Zero argument count follows0x1c4eb8; PIC arithmetic uses pools0x1c50a8/0x1c50ac and references literal **5.1.6** atVA0x3626e8 (file offset0x3626e8). No cross-version equality or active Apache module-loading/version observation is inferred.

The earlier selected PHP package label5.2.13 remains correct for php/php-cli. A generic summary saying only “PHP5.2.13” must now distinguish the bundled module. This refines aggregate applicability without rewriting the earlier report or asserting a security/compatibility issue. Both originals and their labels are retained rather than choosing one universal firmware PHP version.
