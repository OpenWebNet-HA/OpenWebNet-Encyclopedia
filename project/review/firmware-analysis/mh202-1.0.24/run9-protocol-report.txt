## 4. Isolated original-helper verification and its limits

`emulate_normal_suffix_helpers.py` is a fresh MH202-specific harness. It maps the verified original libopen ELF PT_LOAD file bytes and zeroed memory sizes into a private Unicorn address space, then makes the original image read/execute only. It does not run ELF initialization, apply a live loader or execute original PLT bodies. Only the selected helper instruction range is allowed per invocation; unexpected PC, original interrupt, unmapped/protected access or hook cap violation aborts. Each invocation has a10000-step hook cap and a10000-instruction emulator cap. Private object/stack are the only writable guest regions. Host primitive read/write ranges are explicitly bounded to those private regions, with1024-byte C-string/primitive caps.

The only allowed intercepted original PLT addresses are memset`0x54a0`, strcpy`0x5704` and strchr`0x53d4`. Their host callbacks implement the ordinary semantics on private fixtures and return to original LR. Their callbacks are counted separately from native instruction visits; no real library is delegated to. A private EXIT hook stops the emulation after the original return, counted as a boundary.
