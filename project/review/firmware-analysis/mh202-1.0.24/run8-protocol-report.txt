- It obtains raw[8] at`0x2714..0x271c`.
- Only when this character is ASCII`9` does it replace it with raw[11] (`0x2720..0x2734`). Both retained examples have raw[8]=`1`, so this alternate extraction is skipped.
- It sends that single character through the selected numeric stream conversion, then calls the integer overload at`0x2788`, preserving the diagnostic flag.

The integer overload`0x2350..0x2410` iterates the original WHO→system map by key. For a system match, `0x23ac` checks the WHO key against1000. A matching normal WHO<1000 is returned only when diagnostic=false; with diagnostic=true it continues. A matching WHO>=1000 is returned directly. End-of-map returns−1.

Selected initializer span`0x2410..0x2470` constructs WHO1/system1 and WHO1001/system1 pairs. The map construction/range is retained at`0x25f8..0x26c8`. Under completed ordinary std::map initialization, system1 with diagnostic=true skips key1 and returns **1001**. This selected reverse lookup is not arithmetic `1000+system` and does not require recreating the whole earlier16-pair inventory. It also does not promote the distinct absent generic WHO1000 mapping to a global parser rejection.

The original five-argument libopen read-dimension builder is `0xb680..0xb800`. It creates a null object, builds the raw string at object+`0x5e3c`, and concatenates exact original pieces:

WHO and WHERE are the two results above; run7's original DIM argument is1 and four decimal value strings are reused read-only. Original PIC pool/target identities for `*#`,`*`,`##` are recorded in `selected-original-literals.json`. The final suffix uses pool`0xb7f8` plus14, not a separately invented literal. Builder also records the raw length at object+`0x5e38`, trims possible final CR/LF bytes and zero-terminates its chosen end. The two constructed cases have no CR/LF.

At **`0xb7e8`** the builder restores its frame and tailbranches to imported **IsCorrect**, whose same-build candidate definition is`0xad60`.
