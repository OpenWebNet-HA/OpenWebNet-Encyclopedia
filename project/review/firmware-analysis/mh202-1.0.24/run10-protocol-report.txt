The callbacks operate only on explicit guest addresses, never delegate to original libc or a host target service. The `cstring` primitive reads are capped at4096bytes. The strtok token scanner separately checks each scanned byte against a permitted mapped region; it has no4096-byte token-scan cap, and the selected fixture strings are short. Writes are bounded to the private object/stack; the argument region and original image are not writable. `strncpy` models ordinary truncation/padding; `strtok` updates a private per-case token state and guest delimiter bytes; comparison models preserve the required sign/equality. The **only** sprintf format allowed in this selected path is the literal supplied WHERE`0` without `%`; another format aborts instead of adding speculative format semantics. No allocator callback was needed by this C-interface normal path; an unknown call aborts.

Original ELF PT_LOAD file bytes/memory sizes are mapped privately, then the entire original image is read/execute. The allowed original-PC ranges are exactly the six native definitions above. Unknown PC, original interrupt or invalid/protected memory access aborts. Per-case code-hook and emulator instruction caps are100000. A private EXIT boundary stops after the native top-level return. No ELF constructors or actual PLT resolver run, no original syscalls or target processes run, and no live I/O is connected. Host Python/binutils only read/write authorized evidence and implement the explicit CPU/primitive model.

The modeled C primitive/state/provider contracts bound applicability. This is not evidence that every input, allocator state, thread interaction, global strtok state, live library provider or device environment behaves identically. Only the two normal supplied C-interface cases are tested; no malformed/suffix/authentication matrix is added.
