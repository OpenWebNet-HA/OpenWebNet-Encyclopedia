# MH202 ScenarioSuite local project XML to scenario collection

The original Suite Core has a local filesystem/XML loader that inserts a returned `cScenario` object into the same newly published `cScenariosCollection` container. This narrows the upstream object-source gap in the earlier compiler study: the loader accepts per-scenario XML files and retains their deserialized objects, while the earlier `CompileAll` accepts a supplied collection of those declared types. A real caller passing the loader's output to that compiler, a genuine populated project, successful provider operations and emitted scripts are still unproved.
