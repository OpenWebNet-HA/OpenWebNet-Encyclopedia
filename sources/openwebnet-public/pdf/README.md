# Public OpenWebNet PDFs

This directory contains 19 canonical copies of publicly distributed OpenWebNet protocol documents supplied as the public documentation corpus.

The files are retained byte-for-byte as source evidence. Exact byte sizes and SHA-256 fingerprints are recorded in the [Source Manifest](../../manifest.yaml).

The corpus includes the OpenWebNet introduction, HMAC documentation, Zigbee documentation, and `WHO`-specific documents for `WHO 0`, `1`, `2`, `3`, `4`, `5`, `6`, `7`, `13`, `15`/`25`, `16`, `17`, `18`, `22`, `24`, and `25`.

These PDFs describe the published protocol, but some predate functionality represented by MyHOME Suite 3.5.38. The documentation project therefore preserves both layers of evidence: published protocol documentation and current implementation artifacts. Discrepancies are documented explicitly rather than silently reconciled.
