# Public OpenWebNet PDFs

This directory contains canonical copies of publicly distributed OpenWebNet protocol documentation.

The files are retained as source evidence and must remain byte-identical to the acquired originals. Their fingerprints, provenance, document topics, and acquisition information will be recorded in the source manifest.

These documents describe the published OpenWebNet protocol but may predate functionality present in MyHOME Suite 3.5.38. Where published documentation and the current implementation differ, the documentation project records the distinction explicitly.
