# Public OpenWebNet Documentation

This source set contains canonical copies of publicly distributed OpenWebNet protocol documents published by BTicino and Legrand.

## Contents

The [`pdf/`](pdf/) directory contains the OpenWebNet introduction, HMAC and Zigbee documentation, and the available WHO-specific protocol documents.

Exact byte sizes and SHA-256 fingerprints are maintained in [`../manifest.yaml`](../manifest.yaml).

## Use in this reference

The public documents define published OpenWebNet terminology, frame syntax, and functional protocol behavior. Some documents predate functionality represented by MyHOME Suite 3.5.38. Where the published documents and current implementation artifacts differ, the distinction is documented rather than silently reconciled.

The public corpus and MyHOME Suite corpus therefore serve complementary roles: the former documents the published protocol, while the latter records implementation structures present in the current canonical software version.
