# MyHOME Suite 3.5.38

This source set records canonical implementation artifacts from MyHOME Suite 3.5.38 without redistributing the vendor files in Git.

## Contents

| Area | Contents |
| --- | --- |
| [MyHOME Suite 3.5.38 Databases](databases/) | Metadata for MHCatalogue.db, OPEN.db, both ScenarioDevices.sqlite variants, and rules.db3 |
| [MyHOME Suite 3.5.38 Support Files](support/) | Metadata for non-database support material, including OpenQuery.txt |

The original installation paths, byte sizes, SHA-256 fingerprints, private archive object keys, and installer provenance are recorded in the [Source Manifest](../../manifest.yaml).

## Provenance

These artifacts were copied from a MyHOME Suite 3.5.38 installation and are retained as implementation evidence in the private OpenWebNet-HA data archive. Git contains metadata and analysis only.

Maintainer-only evidence checks materialize the exact archived bytes by SHA-256 into a temporary directory and verify the fingerprint before use.

Canonical vendor artifacts must not be modified to incorporate inferred relationships, normalized data, or protocol interpretations.
