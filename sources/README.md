# Canonical Sources

This directory contains canonical source material used to document and reverse-engineer OpenWebNet.

Files under `sources/` are preserved as original evidence. Canonical binary source files must not be modified to encode inferred relationships, corrections, or other analysis. Derived material belongs elsewhere in the repository.

## Source sets

- `myhome-suite/3.5.38/` — files extracted unmodified from MyHOME Suite 3.5.38.
- `openwebnet-public/` — publicly distributed OpenWebNet protocol documentation.

A corpus manifest with cryptographic fingerprints and detailed provenance will be maintained in this directory.

Network captures are intentionally excluded because they may contain private installation information.
