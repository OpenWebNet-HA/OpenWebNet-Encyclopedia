# Validate and Program a Change

## Goal

Demonstrate how one requested high-level change becomes a validated complete programming payload and verified installed state.

## Example outline

1. Record the requested semantic change.
2. Resolve Device, firmware, internal slot, current Object, and target Object.
3. Resolve the applicable `EN_CONF` definition.
4. Construct the base range and apply the Object/firmware filter.
5. Evaluate conditions, conversions, and linked properties.
6. Determine physical and Virtual representation.
7. Rebuild and validate the complete Device payload.
8. Select the canonical programming scenario.
9. Record every transmitted frame and response.
10. Perform a fresh diagnostic interview and compare the entire affected state.
