# Lost Reference Recovery

This directory tracks historical OpenWebNet references that are discovered on mirrors, standards archives, obsolete vendor sites, or secondary repositories before they are incorporated into the canonical documentation corpus.

Recovery records distinguish discovery from retrieval. A source is not considered archived as original bytes until an exact downloadable artifact has been recovered and fingerprinted. Mirror text or rendered previews may establish document identity and contents, but must not be represented as the original file.

Priority evidence classes include standards working documents and drafts, manufacturer protocol/engineering documents, SDK and integrator material, and preserved implementation evidence.
