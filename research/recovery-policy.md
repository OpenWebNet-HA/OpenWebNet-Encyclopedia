# Lost-reference recovery policy

The goal of this branch is preservation of OpenWebNet / MyHome technical history before sources disappear.

## Source-origin policy

- Preserve a relevant artifact whenever a recoverable copy can be obtained, regardless of whether it is hosted by BTicino/Legrand.
- Prefer manufacturer-original bytes when available, but do not delay preservation waiting for an official source.
- Accept credible mirrors, software archives, reseller caches, forum attachments, conference/event mirrors, academic repositories, web archives, and other third-party copies.
- Record the actual recovery source, original filename when known, byte size, SHA-256, and any evidence about publisher/authorship/version.
- Never relabel a mirror as an issuer-original artifact. Provenance describes where the recovered bytes came from.
- When later copies are found, compare hashes. Keep one canonical byte-identical object while recording independent corroborating sources where useful.
- Preserve incomplete or transformed copies (slide images, HTML captures, transcripts) when originals are unavailable, but mark them explicitly as such and keep hunting for original bytes.
- Historical software/firmware should be preserved even if only third-party mirrors survive.

Source quality affects confidence and provenance, not preservation eligibility.
