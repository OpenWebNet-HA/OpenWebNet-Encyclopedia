# Address Programming

Address programming assigns the effective functional address of a Module according to its selected Object and system.

## Planned coverage

- applicable address rule selection;
- Lighting/Automation `A`/`PL`;
- group, environment, CEN, zone, and other system-specific forms;
- virtual and advanced encodings;
- address range and padding;
- firmware and Object restrictions;
- physical-configurator counterparts;
- address errors;
- diagnostic read-back through `DIMENSION 32`.

The storage range of a protocol field does not establish that every value is valid for every system or Object.
