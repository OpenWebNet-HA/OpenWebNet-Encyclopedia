# Programming `WHAT` Reference

This page will provide the canonical programming `WHAT` registry extracted from `OPEN.db`.

## Table format

| `WHAT` | Direction | Frame | Scope | Meaning | Sequence context |
| ---: | --- | --- | --- | --- | --- |

Each value will be documented within its programming `WHO` and active sequence. Equal numeric values in diagnostics, functional control, or another programming family do not imply equal semantics.

The reference will distinguish selection, transfer, commit, termination, abort, and error-related operations without inferring behavior from the numeric value alone.
