# Complete Device Index

This page is the exhaustive commercial identity lookup for the [Devices](README.md) section.

Use Ctrl-F to search for the exact brand, SKU, catalogue number, or commercial reference printed on a Device or found in documentation.

## Index rules

- Use one row per known brand / SKU combination.
- Several rows may link to the same technical Device definition.
- Do not designate one SKU as canonical merely to choose a page name.
- Record equivalence/package relationships only when supported by evidence.
- Keep candidate or uncertain relationships visibly qualified.
- Add a commercial identity as soon as it is useful for discovery, even if the corresponding Device definition is incomplete.

The mechanically extracted [Database Inventory](inventory/) contains every catalogue record. This page contains commercial identities already associated with curated `OWN-DEV-*` definitions.
