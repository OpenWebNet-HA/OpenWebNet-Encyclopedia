# Device Coverage

This index tracks the current state of product-specific documentation.

It is both a navigation aid and a research backlog. A missing or incomplete entry does not mean that a product is unsupported by OpenWebNet.

## Coverage fields

| Field | Meaning |
| --- | --- |
| Device page | A product-specific Encyclopedia page exists |
| Official sources | At least one authoritative product document is inventoried |
| Identity | The product can be tied to protocol or implementation identity evidence |
| Hardware evidence | At least one observation from known physical hardware exists |
| Functions | Modules, Objects, roles, and relevant `WHO` values are documented |
| Configuration | Supported configuration methods and parameters are documented |
| Constraints | Material configuration ranges, conditions, and cross-parameter constraints are documented |

Use **Complete**, **Partial**, **Unknown**, or **Not applicable** where a simple yes/no would hide important gaps.
