# Device Categories

Categories provide human navigation across [Device Definitions](../definitions/). They do not determine canonical Device identity or filesystem location.

A Device may appear in several categories at the same time.

## Current categories

| Category | Page |
| --- | --- |
| Actuators | [Actuators](actuators.md) |
| Commands | [Commands](commands.md) |
| Multifunction Devices | [Multifunction Devices](multifunction-devices.md) |
| Sensors | [Sensors](sensors.md) |
| Gateways and Interfaces | [Gateways and Interfaces](gateways-and-interfaces.md) |

Additional likely categories include Sensors, Thermoregulation, Burglar Alarm, Energy Management, Scenarios, and Audio / Video.

The taxonomy may evolve as the documented Device set expands.

Each category page uses a simple table linking to canonical Device definitions and does not duplicate their full technical content.
