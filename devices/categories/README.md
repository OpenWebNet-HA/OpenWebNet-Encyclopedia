# Device Categories

Categories provide human navigation across [Device Definitions](../definitions/). They do not determine canonical Device identity or filesystem location.

A Device may appear in several categories at the same time.

## Initial category set

Create category pages as Device coverage grows. Likely categories include:

- Actuators
- Commands
- Multifunction Devices
- Sensors
- Thermoregulation
- Burglar Alarm
- Gateways and Interfaces
- Energy Management
- Scenarios
- Audio / Video

The taxonomy may evolve as the documented Device set expands.

Each category page should use a simple table linking to the canonical Device definitions and should not duplicate the full technical content of those pages.
