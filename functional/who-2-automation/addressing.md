# Addressing

Automation shares the A/PL address-rule family used by Lighting. MyHOME Suite 3.5.38 represents point-to-point `[A][PL]`, environment `[A]`, and advanced address forms through system-specific address rules.

A numeric `WHERE` must therefore be interpreted according to the Automation address rule in use rather than assumed to be one universal address form. See [`../../protocol/addressing.md`](../../protocol/addressing.md).
