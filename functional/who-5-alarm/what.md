# `WHAT` Reference

| `WHAT` | Meaning |
| ---: | --- |
| `0` | Maintenance |
| `1` | Activation |
| `2` | Disactivation |
| `3` | Delay end |
| `4` | System battery fault |
| `5` | Battery OK |
| `6` | No network |
| `7` | Network present |
| `8` | Engage |
| `9` | Disengage |
| `10` | Battery unloads |
| `11` | Active zone |
| `12` | Technical alarm |
| `13` | Reset technical alarm |
| `14` | No reception / `ACK` peripheral device |
| `15` | Intrusion alarm |
| `16` | 24-hour alarm / tampering |
| `17` | Anti-panic alarm |
| `18` | Non-active zone |
| `26` | Start programming |
| `27` | Stop programming |
| `31` | Silent alarm |

The labels above follow the published `WHO 5` vocabulary. Programming-related values are part of that published functional namespace and should not be confused with the separate MyHOME Suite device-programming protocol documented under [`../../programming/`](../../programming/).
