# Overview

CEN and CEN+ command events are represented by OpenWebNet systems including `WHO` `15` and `25`.

## Reference scope

This section will document CEN and CEN+ event forms, virtual addressing, button and event parameters, applicable `WHAT` values, and the distinct uses of the relevant `WHO` systems.

The semantics of `WHO` `15` and `WHO` `25` remain system-specific even where both participate in CEN-related functions.

See [`../../protocol/`](../../protocol/) for common OpenWebNet frame syntax.
