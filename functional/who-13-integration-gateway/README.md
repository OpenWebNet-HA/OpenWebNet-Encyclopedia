# Overview

`WHO 13` defines Integration / Gateway functions. It has a dedicated published OpenWebNet specification and is also represented as a functional system in the MyHOME Suite protocol corpus.

Its `WHAT`, `WHERE`, and parameters are system-specific gateway/integration operations and must be decoded in the `WHO 13` namespace. They are separate from transport-level gateway connection, authentication, and `ACK`/`NACK` handling documented under [`../../protocol/`](../../protocol/).

The canonical public source is `WHO_13.pdf` under [`../../sources/openwebnet-public/pdf/`](../../sources/openwebnet-public/pdf/).
