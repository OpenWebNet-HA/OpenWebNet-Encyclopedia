# Overview

CEN+ functions are carried within the `WHO 25` namespace. They include CEN+ command events addressed through the CEN+ virtual-address model.

The canonical protocol context for every operation on this page is therefore `WHO 25`. Related CEN functions under `WHO 15` are documented in [`../who-15-cen/`](../who-15-cen/).

Detailed `WHAT`, `WHERE`, and parameter tables will be added as the `WHO 25` reference is developed.
