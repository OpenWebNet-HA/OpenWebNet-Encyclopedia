# Dry Contact and IR

Dry-contact and IR functions are carried within the `WHO 25` namespace while remaining functionally distinct from CEN+.

## `WHAT`

| `WHAT` | Function |
| ---: | --- |
| `31` | Dry-contact function |
| `32` | IR function |

These values are interpreted only in the `WHO 25` context. Their `WHERE` and parameter structure follows the corresponding `WHO 25` function rather than the CEN+ virtual-address grammar merely because both families share the same `WHO`.

## Functional navigation

Dry contacts are indexed separately in [`../README.md`](../README.md) so readers looking by hardware/function can reach this page directly while the canonical reference remains under `WHO 25`.
