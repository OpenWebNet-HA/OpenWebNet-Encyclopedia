# Overview

The MyHOME_Suite `OPEN.db` protocol definitions represent `WHO 99` as the Service Identification namespace.

Service-identification operations are protocol services rather than an ordinary home-automation function such as Lighting or Automation. The namespace is retained under `functional/` because it is part of the known non-diagnostic `WHO` catalogue; session-level behavior should be cross-referenced with [`../../protocol/`](../../protocol/) where applicable.

The current corpus establishes service-identification operations but does not justify a broader inferred `WHAT` vocabulary.
