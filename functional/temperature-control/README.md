# Overview

Temperature Control uses `WHO` `4` and defines its own zone-oriented addressing and thermoregulation operations.

## Reference scope

This section will document temperature-control `WHAT` values, `WHERE` grammar, `DIMENSION` identifiers, temperature encoding, operating states, actuator and probe information, and system-specific frame forms.

See [`../../protocol/addressing.md`](../../protocol/addressing.md) for the common addressing model and [`../../protocol/dimensions.md`](../../protocol/dimensions.md) for `DIMENSION` frame structure.
