# Overview

Scenarios use `WHO` `0` to invoke and manage scenario functions through OpenWebNet.

The functional scenario protocol is distinct from the higher-level MyHOME Suite scenario-engine model documented under `scenario-engine/`.

## Reference scope

This section will document scenario `WHAT` values, `WHERE` addressing, programming-related functional operations where applicable, and frame examples defined for `WHO` `0`.

See [`../../protocol/`](../../protocol/) for common OpenWebNet frame syntax.
